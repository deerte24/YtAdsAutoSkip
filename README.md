# Overview
This is a project for my personal web browser (Opera GX). Usually, when watching YouTube and an ad appears, users sometimes can’t click the “skip ad” button for various reasons. A similar add-on actually exists for Opera GX, but it doesn’t work well, so based on that experience, I created this add-on, and so far (Version 1.0), it’s working well.

Note: This add-on will only click the “skip ads” button when it appears; it does not skip ads automatically.

# Browser usage
This add-on can be used as long as the browser is Chromium-based

# How to use
Since this is still an early version and I haven't uploaded it to the Opera Store or the Chrome Store yet, you'll have to install it manually.

- Fork this project and save it to your local machine or device.
- Open Opera GX and go to the Extensions menu.
- Enable developer mode in the Extensions menu.
- Then select “Load unpublished extensions.”
- Locate the folder containing this forked project.
- Once selected, the add-on will appear in the Extensions menu; enable it.

ps: The steps for using it in Chrome are more or less the same
